## Заметки

### Стратегический фокус

По нескольким денежным запросам упёрлись в **авторитет домена** (проводка pos 57–77,
окна 18.5) — on-page уже максимум, показы есть, кликов нет. → Приоритет на **беклинки**
(embed-виджеты + контекстные do-follow сети) и **long-tail через контент** (глоссарий,
Q&A, галереи), где авторитет не нужен. Докрутку делаем ТОЛЬКО по данным GSC-позиций
(окупается при pos ≈8–20). См. [[prodom-seo-opportunities]]. Монетизация — ставка на
показы (AdSense+РСЯ), партнёрка в дополнение; подробно в [ADVERTISING.md](ADVERTISING.md).

### Ждём / за владельцем

- **~20.10: замерить эффект правок** смета/окна/проводка по GSC (переранжирование 2–4 недели).
- **JS-цели в Метрике** по именам событий (calc_submit, glossary_search, affiliate_click,
  slider_click, fab_open, donate_click, tg_subscribe…) — код уже шлёт. См. [[prodom-analytics-plan]].

### Сознательно НЕ делаем

Форум (модерация соло), видео (дорого), платные услуги/подписка (фиат-рельсы КГ + соло),
сетка «все ко всем» в ссылках (link scheme). См. [[organic-only-no-ad-budget]], [[kyrgyzstan-payment-rails]].
