## Как проверять после правок

```bash
# сервер (порт может остаться занят от прошлой сессии — сначала освободить)
lsof -ti:8899 | xargs kill -9 2>/dev/null
php -S 127.0.0.1:8899 -t . &

# синтаксис реестра
php -l includes/all-articles-meta.php

# все статьи: ошибки, пустые страницы, FAQ-схема
php -r 'require_once "includes/all-articles-meta.php";
  foreach (array_keys(domexpert_all_articles_meta()) as $s) echo $s,"\n";' | while read s; do
  b=$(curl -s "http://127.0.0.1:8899/article.php?slug=$s")
  echo "$b" | grep -qiE "Fatal error|Warning:|Notice:" && echo "ОШИБКА: $s"
  [ ${#b} -lt 5000 ] && echo "ПУСТАЯ: $s"
done

# реестр ↔ файлы и битые внутренние ссылки
php -r 'require_once "includes/all-articles-meta.php";
  $k=domexpert_all_articles_meta(); $f=[];
  foreach (glob("articles/*/*.html") as $x) $f[basename($x,".html")]=1;
  print_r(array_diff(array_keys($k),array_keys($f)));
  $bad=[]; foreach (glob("articles/*/*.html") as $x) {
    preg_match_all("#/article/([a-z0-9-]+)/#", file_get_contents($x), $m);
    foreach (array_unique($m[1]) as $s) if (!isset($k[$s])) $bad[$s]=1; }
  print_r(array_keys($bad));'

# опечатки: кириллица в hex-цветах, латиница внутри русских слов
grep -rl 'solid #[0-9a-fA-F]*[а-яё]' articles/
grep -rno '[а-яё][a-z]\{2,\}[а-яё]' articles/ | grep -v 'href\|src='

# служебный жаргон в текстах для читателя
grep -rniE 'для seo|seo-практика|ключев(ых|ые) запрос|семантик' articles/

# sitemap
python3 -c "import xml.dom.minidom; xml.dom.minidom.parse('sitemap.xml')"
```

**Важно про сервер:** встроенный PHP-сервер не применяет `.htaccess`, поэтому ЧПУ вида `/category/remont/` на нём не работают — проверять нужно через `category.php?cat=remont`. Если порт 8899 занят зависшим процессом, PHP молча не поднимется, и запросы будет обслуживать старый процесс, отдавая 404, — проверки при этом выглядят провалившимися без реальной причины.

## При добавлении новой статьи

0. Найти тему в карте кластеров `SEMANTIKA.md`. Если посадочная по теме уже есть — статья не пишется, дорабатывается существующая. Если кластера нет — в документ добавляется строка.
1. Файл в `articles/<категория>/<слаг>.html` — фрагмент без `<html>` и `<head>`.
2. Запись в `includes/all-articles-meta.php`: `cat`, `title`, `desc`, `date`, `readTime`. Title до 70 символов, desc до 180.
3. Строка в `sitemap.xml`.
4. Подпись обложки в `scripts/make_missing_covers.py`, затем `.venv-img/bin/python scripts/make_missing_covers.py`.
5. Блок «Частые вопросы» с вопросами в `<h3>` — иначе не будет FAQPage.
6. Проверить рендер и целостность командами выше.

**Осторожно с правкой реестра через `preg_replace`.** Обратные ссылки вида `$4` перед цифрой склеиваются в `$42` и молча затирают поле — так 11 августа снесло `date` и `readTime` у шести статей. Либо строить строку целиком, либо использовать `${4}`.

**При добавлении калькулятора:** разметка в `calc-forms/<слаг>.html`, запись в `includes/all-calculators-meta.php` (поле `related` даёт двустороннюю связь со статьями автоматически), строка в `sitemap.xml`. Расчёт стоит прогнать на граничных сценариях — функцию из `<script>` можно выдернуть и выполнить в Node со стабом `DomCalc.register`.
