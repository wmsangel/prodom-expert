Розетка на балконе, террасе или у входной двери экономит удлинители для уборки, зарядки и сезонной подсветки. Наружная установка требует короба с подходящей степенью защиты IP, кабеля с учётом температуры и защитных устройств в щите — иначе УЗО будет отключать линию без видимых причин.

Какой IP выбрать

  • IP44 и выше — для зон под навесом без прямого попадания дождя.
  • IP55–IP66 — для открытых фасадов и стен с водой «со всех сторон».

Цифры в маркировке должны относиться именно к готовому блоку «под ключ»: одна только «влагозащитная» крышка поверх внутренней розетки без герметичного ввода кабеля защиту не даёт.

Кабель и укладка

Используйте кабель, допустимый для температуры окружающей среды на балконе (зимой там может быть под нулём при открытой фрамуге). Не тяните силовую линию параллельно слаботочке без экрана — об этом в материале о прокладке интернета при ремонте. Ввод в короб — через герметичный кабельный ввод, без скотча «наобум».

Щит и УЗО

Линию желательно вынести на отдельный автомат и устройство защитного отключения с номиналом утечки 30 мА для розеточной группы. Если розетка будет использоваться для уличной подсветки, согласуйте суммарную нагрузку с запасом по мощности дома — см. также LED-прожекторы и безопасность линии.

Эксплуатация зимой

Если колодка обмерзает изнутри, значит конденсат или дождь попадают через неплотности — выключайте автомат до ремонта узла. На постоянно отапливаемом балконе отлив влаги проще, но проверка раз в сезон всё равно нужна.
