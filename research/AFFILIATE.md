## API
Токен: `~/.config/seo-stats/leads-su-api-token.txt` (читать, не печатать).
`GET https://api.leads.su/webmaster/offers?token=<t>&limit=500` и `/offers/<id>`.
Словарей категорий/ГЕО и **генерации ссылок в API нет** — подключение офферов и получение ссылок только через кабинет (Chrome).

## Sub-id
Параметр sub-id для атрибуции страницы-источника — уточнить при генерации ссылки в кабинете
(обычно `subid`/`sub_id` в ссылке оффера). Правило: проверять, что sub-id реально проставляется,
кликом по ссылке на боевом домене.
