# Оформление профиля Instagram — ДомЭксперт

Единый источник данных — `../profile.js`. Картинки генерирует `../gen-profile.js`.
Отправка владельцу в бот: `node scripts/social/telegram-daily.mjs --profile`.

## 1. Аватар
`avatar.png` — 1080×1080, графит + охра, знак (дом с галочкой) в центре, вордмарк «ДомЭксперт».
В IG: фото профиля. Слать файлом (без сжатия) + превью.

## 2. Имя профиля (≤30) + @username
- Имя: **ДомЭксперт · Ремонт квартиры** (28 символов; ключевое слово «ремонт квартиры» для поиска IG).
- Варианты @username (занять первый свободный): `@prodom.expert` · `@domexpert.remont` · `@prodom.expert.ru`

## 3. Bio (≤150)
```
Ремонт своими руками: электрика, сантехника, отделка.
Калькуляторы материалов и сметы — бесплатно.
Практика, не реклама 👇
```

## 4. Ссылка в профиле (с UTM)
`https://prodom-expert.ru/?utm_source=instagram&utm_medium=social&utm_campaign=bio`

## 5. Тип и категория
- Тип аккаунта: **Автор (Creator)** — контент-бренд, под именем показывается категория, есть статистика.
  (Business — если хочется кнопку «Эл. адрес» в профиле.)
- Категория: **«Образование»** (альт.: «Блогер» / «Издание»).

## 6. Обложки «Актуального» (1080×1920, без текста — круг обрезает)
Файлы `hl-*.png` + названия для IG:
1. `hl-electrika.png` — **Электрика**
2. `hl-santehnika.png` — **Сантехника**
3. `hl-otdelka.png` — **Отделка**
4. `hl-raschety.png` — **Расчёты**
5. `hl-cheklist.png` — **Чек-листы**
6. `hl-mify.png` — **Мифы**

## 7. Контакт
Рабочая почта: `info@prodom-expert.ru` (используется в privacy/about сайта).

## 8. Закрепить 3 поста
- **Разбор (Пн)** — сечение кабеля: показывает пользу и экспертизу.
- **Чек-лист (Ср)** — закупки до старта: широкий интерес, легко сохраняют.
- **Промо (Чт)** — калькулятор сметы: ведёт на инструмент сайта.

## 9. Чек-лист «что нажать в Instagram»
1. Профиль → «Редактировать профиль».
2. Фото профиля → загрузить `avatar.png`.
3. Имя → вставить «ДомЭксперт · Ремонт квартиры».
4. Имя пользователя → занять свободный из вариантов.
5. Описание → вставить Bio (3 строки).
6. Сайт → вставить ссылку с UTM.
7. Настройки → Аккаунт → тип «Автор», категория «Образование», показать категорию; контакт — почта.
8. Актуальное → создать 6 историй, обложки `hl-*.png`, имена из списка; закрепить 3 поста.
